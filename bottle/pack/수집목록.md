## 사용자 설명 (11/18) — 공정 순서
1. 턴테이블 : 충전실에서 캡핑 완료된 제품이 배출되어 임시 보관, 버퍼가 없으면 라인에 바로 투입
2. 라벨 인쇄
3. 라벨 부착 — 인쇄 비전 검사 · 라벨러 후단 리젝터
4. 부착형 설명서 부착 — 설명서 유무 리젝터는 없음
5. 중량선별기 — 설명서 유무 검증(중량) 및 리젝트
6. 작업자 1 : 바코드 인식 (마트 계산대처럼 거치형 판독기에 병을 대고 찍음)
7. 작업자 2 : 박스 포장 및 AG 라벨 부착 — 작업자 1이 박스 내 포장 수(예 40병)만큼 찍으면 박스 AG 라벨이 자동 발행
8. 파렛트 적재

※ 사진 · 영상 원본, 제품명 · 회사명 · 실 표시 · 제조번호 등 화면 내용은 기록하지 않음 (보안 원칙)

## 사용자 설명 (11/18) — 비전 PC 화면
- 작업자 조작은 **ON/OFF(시작 · 중지)만** (설정 변경 없음)
- 화면 구성 (사진) : 왼쪽 = 모델명 · 상품코드(GTIN) · 시작/중지 버튼 · 판독 기록 목록(시각 · 상품코드 · 유통일자 · 로트번호 · 일련번호) · 현재 판독 데이터 4칸
  오른쪽 = 비전 촬영 화면(제조번호 · 사용기한 글자 영역과 2D 코드 영역에 판정 사각형) · TOTAL / GOOD / NG 수 · 큰 판정 표시(OK 녹색 · NG 적색) · 메시지 줄 · Reset
- ※ 회사명 · 제품명 · 코드 값은 기록하지 않음

## 사용자 설명 (11/18) — 라벨 인쇄기 화면
- 작업자 조작은 **ON/OFF만** (인쇄 내용은 작업 데이터로 들어옴 · 화면에서 입력하지 않음)
- 화면 구성 (사진) : 위 = 사용자 등급 · 상태(실행) · 날짜 시각, 왼쪽 세로 메뉴 = 잠깐 멈춤 · 작업 선택 · 조정 · 메뉴 · 꺼짐,
  가운데 = 작업 이름 · 인쇄 미리보기(제조번호 · 사용기한 큰 글자 · 2D 코드 · GS1 표기 두 줄), 오른쪽 = 리본 잔량 막대(남은 시간 · %) · 총 인쇄 횟수 · 배치 인쇄 횟수 · 순간 평균 속도(개/분), 실행 중 바탕 녹색
