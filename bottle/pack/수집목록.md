## 사용자 설명 (11/18) — 공정 순서
1. 턴테이블 : 충전실에서 캡핑 완료된 제품이 배출되어 임시 보관, 버퍼가 없으면 라인에 바로 투입
2. 라벨 인쇄
3. 라벨 부착 — 인쇄 비전 검사 · 라벨러 후단 리젝터
4. 부착형 설명서 부착 — 설명서 유무 리젝터는 없음
5. 중량선별기 — 설명서 유무 검증(중량) 및 리젝트
6. 작업자 1 : 바코드 인식 (마트 계산대처럼 거치형 판독기에 병을 대고 찍음)
7. 작업자 2 : 박스 포장 및 AG 라벨 부착 — 작업자 1이 박스 내 포장 수(예 40병)만큼 찍으면 박스 AG 라벨이 자동 발행
8. 파렛트 적재

※ 사진 · 영상 원본, 제품명 · 회사명 · 실 표시 · 제조번호 등 화면 내용은 기록하지 않음 (보안 원칙)

## 사용자 설명 (11/18) — 비전 PC 화면
- 작업자 조작은 **ON/OFF(시작 · 중지)만** (설정 변경 없음)
- 화면 구성 (사진) : 왼쪽 = 모델명 · 상품코드(GTIN) · 시작/중지 버튼 · 판독 기록 목록(시각 · 상품코드 · 유통일자 · 로트번호 · 일련번호) · 현재 판독 데이터 4칸
  오른쪽 = 비전 촬영 화면(제조번호 · 사용기한 글자 영역과 2D 코드 영역에 판정 사각형) · TOTAL / GOOD / NG 수 · 큰 판정 표시(OK 녹색 · NG 적색) · 메시지 줄 · Reset
- ※ 회사명 · 제품명 · 코드 값은 기록하지 않음

## 사용자 설명 (11/18) — 라벨 인쇄기 화면
- 작업자 조작은 **ON/OFF만** (인쇄 내용은 작업 데이터로 들어옴 · 화면에서 입력하지 않음)
- 화면 구성 (사진) : 위 = 사용자 등급 · 상태(실행) · 날짜 시각, 왼쪽 세로 메뉴 = 잠깐 멈춤 · 작업 선택 · 조정 · 메뉴 · 꺼짐,
  가운데 = 작업 이름 · 인쇄 미리보기(제조번호 · 사용기한 큰 글자 · 2D 코드 · GS1 표기 두 줄), 오른쪽 = 리본 잔량 막대(남은 시간 · %) · 총 인쇄 횟수 · 배치 인쇄 횟수 · 순간 평균 속도(개/분), 실행 중 바탕 녹색

## 사용자 설명 (11/18) — 라벨러 판넬
- 작업자 조작은 **ON/OFF만** (자동운전 RUN / STOP · 프린터 ON / OFF)
- 판넬 구성 (사진) : 터치 화면(자동화면) = 날짜 · 시각, 헤드 현재값, 헤드 운전 선택 · 수량 카운트 · RESET, 자동운전 RUN · STOP, 프린터 ON · OFF, 현재 온도,
  아래 탭 수동 · 자동 · 변경 · 수량 · 알람 / 오른쪽 = 전원 램프(녹색) · 전원 키 스위치(잠금 덮개 · LOTO) · 비상정지 / 왼쪽 아래 노브
- 판넬 표지 : 관계자 외 조작 금지 · 비정형 작업 시 절차(운전 정지 · 전원 차단 LOTO → 정비 · 청소 → 사람 확인 후 LOTO 해제 · 재가동) → IDT 이상사례 조치 절차에 반영 후보

## 사용자 설명 (11/18) — 부착형 설명서 부착기
- **하드웨어만 구현** (소프트웨어 화면 없음) · 작업자 조작은 **ON/OFF만**
- 구성 (사진) : 라벨 컨트롤러 = 카운터(7세그) · 2줄 LCD(RUN MODE) · OPERATOR 버튼 F1 · F2 · I(녹) · O(적) · EDIT 방향키 · M · Enter · 로커 스위치 2개(적색 점등 · MAIN POWER) · 적색 경광등
  아래 전원함 = 전원 키 스위치(잠금 덮개 · LOTO) · 전원 ON 램프(적) · 비상정지 / 옆 높이 조정 핸들(위치 카운터)

## 사용자 설명 (11/18) — 중량선별기
- 작업자 조작은 **중량 세팅(품목 기준 · 상하한)과 ON/OFF(가동 RUN · 정지 STOP)만**
- 구성 (사진) : 형광 표시창 4줄 = 품목 번호 · 품목명 · PASS 수 · −NG 수 · +NG 수 · TOTAL · EXNG / 판정 램프 MDNG · −NG · PASS · +NG · 컨베이어
  키 = 품목 전환 · F · 설명서 · 화면 · 나가기 · 영점(−0−) · 방향키 · 확인 · 숫자 0~9 · 소수점 · CE · 상한 · 하한 · ± · 입력 / 정지(적) · 가동(녹) 버튼 / 주 전원 회전 스위치(황 · 적)
  본체 표지 = 적격성 평가 표지 · 저울 등급 · 교정 범위 · 최소 눈금 표지 (값 · 번호는 기록하지 않음)
- IDT 반영 : 기동 전 중량 세팅(기준 · 상하한 입력 · 확인) → 시료 시험(정상 · 설명서 없는 병) → RUN

## 집합 포장(AG) PC 화면 (사진 · 11/18)
- 위 탭 : 작업지시 · 작업현황 · 작업이력 / 화상 키보드 · 로그인 사용자 · 비밀번호 변경 (사용자 이름은 기록하지 않음)
- 진행 : 전체(박스) 완료 수 / 지시 박스 수 · 단품(이 박스에 판독한 병) n / 40 · [작업완료] · [일시정지]
- 왼쪽 「비전검사」 : 상태 줄(예 포장 완료) · 판독 램프(녹) · [클리어] · [포장완료] · 판독 목록(번호 · 병 2D 코드 = 상품코드 · 사용기한 · 로트 · 일련번호)
- 오른쪽 「박스바코드 발급」 : [재발급] · [박스조정] · [시험인쇄] · LOT 번호 · 제품코드 · 발급 목록(번호 · P/V/A · 박스 일련번호, 최신 줄 적색)
- 아래 장치 상태 : 데이터 관리 · 핸드 스캐너 · 테이블 스캐너 · 프린터 · DIO
- IDT 반영 (추정 · 확인 필요) : 작업자 1이 병을 판독할 때마다 단품 수 증가 → 40 이 되면 박스 바코드(AG 라벨) 자동 발급 · 전체 +1 → 잘못 판독하면 [클리어], 라벨 훼손 시 [재발급], 마지막 박스(40 미만)는 [포장완료]로 마감 → 지시 수량 끝나면 [작업완료]

## 발행된 박스 AG 라벨 (사진 · 11/18)
- 프린터 : 산업용 열전사 라벨 프린터 — 앞면 표시등(일시정지 · 데이터 · 소모품 · 네트워크) · 화면 · [PAUSE] [FEED] [CANCEL] · 라벨이 앞으로 나옴(이면지 붙은 채)
- 라벨 (가로형 · 약 100 × 60 mm 어림) : 맨 위 1차원 바코드(박스 GS1 코드 · 아래 사람이 읽는 글자) → 제품명 · 포장 규격(입수 EA) · 제조번호 · 사용(유효)기한 · 회사명
- IDT 반영 : AG 화면 단품 40/40 → 프린터에서 라벨 나옴 → 작업자 2가 떼어 봉함한 박스 옆면에 부착 (회사명 · 제품명 · 코드 값은 가상 값 사용)
