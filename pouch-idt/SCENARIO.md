- 작성: 11/10(화) · 상태: **초안, 사용자 승인 대기**
- 근거: `HANDOFF.md` 11·12번(사내 SOP·양식 원본 요약, 사용자 확정 사항). 근거 표기: [SOP] 설비 SOP 원본 / [양식] 라인 클리어런스 양식 / [확정] 사용자 답변 / [IDT] 시뮬레이터 구성상 단순화·해석(실제 절차 아님) / [확인 필요]

## 5. 알람 (충전기 SOP 15종, 명칭만 표시, 빨간색 UI)
- 대응 흐름 [IDT 승계]: 알람 발생·설비 정지 → 원인·조치 판단(선택지 4개) → 현장 조치 → RESET → RUN
- **조치 주체 구분(제안)**: SOP 이상상황 규정상 작업자는 직접 조치하지 않고 비상정지 후 실선임자에게 보고함. 이에 따라 '작업자 조치형'과 '보고형'으로 나눔. 보고형은 정답이 '정지·실선임자 보고'이고, 이후 실선임자 조치는 자동 진행(애니메이션) 후 작업자가 재가동 [SOP 해석, 13번 결정 사항]

- 하한 103.5 g = 105.5 − 2.0 [확정값 산출]

## 7. 결과 화면 (승계)
- 점수, 합격 여부(80점), 채점 항목별 획득·배점, 감점 내역, 알람·이상사례 대응 기록, 소요 시간
- 효과측정용 기록 항목(7단계 ROI 설계 입력): 모드, 점수, 소요 시간, 감점 항목, 힌트 사용 수 [IDT]

## 8. 결정 필요 사항 (사용자 선택)
1. 알람 조치 주체 구분(작업자 조치형 5종 / 보고형 10종) 적용 여부
2. 기동 순서: 예열 리드타임 순(포장실 먼저) / 공정 순(충전실 먼저)
3. 이상사례 C1~C8 채택 범위
4. 목표 생산량(기본·심화)
5. 알람을 '이상사례 해결·재가동 15초 후 발생' 방식(PTP)으로 할지 여부
6. 세척·분해조립·품종 등록 과정 추가 여부
