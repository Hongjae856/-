# 파우치 라인 IDT 교육 시나리오 설계 (2단계 초안 v2)

- 작성: 11/10(화) · 상태: **초안 승인(11/10)**, 잠정 3건(9번 6~8)은 지시 시 변경 (v1 대비 변경: 충전실·포장실 과정 분리, 알람 전부 작업자 직접 조치, 이상사례 재구성, 목표 300카톤)
- 근거 표기: [SOP] 설비 SOP 원본 / [양식] 라인 클리어런스 양식 / [확정] 사용자 답변 / [IDT] 시뮬레이터 구성상 단순화·해석(실제 절차 아님) / [확인 필요]
- 구조 승계: PTP·병충전 라인 IDT — 기본·심화 × 학습·평가 4모드, 학습과 평가는 동일 절차(안내 유무만 다름), 합격 80점, 점수 = 완료 배점 ÷ 총 배점 × 100 − 감점. 이상사례는 PTP 포장라인 방식(정기 시험 → 불합격 → 현장 조치(빨간 !) → 재시험 → 재기동)
- 범위: 정상 생산 1회(작업 전 → 가동 → 생산 → 종료). 세척·분해조립·품종 등록은 제외(9번 결정 사항)
