# 충전기·현장 도면 판독 기준표 (재구성용)
- 작성: 11/11 · 근거: 사용자 제공 충전기 상세 도면(평면·정면·측면), 현장 전체 평면 배치도(실 코드는 보안상 기록하지 않음)
- 원칙(사용자 지시 11/11): 도면을 꼼꼼히 보고 임의로 단순화하지 않는다. 숫자가 없는 부위는 도면 비율로 산출해 [도면 비율]로 표기한다.

## 1. 충전기 치수 (도면 표기값)
| 항목 | 값 (mm) |
|---|---|
| 전체 폭 (프레임 + 계단) | 4,441.47 = 2,855 + 1,586.47 |
| 프레임 폭 구성 | 653.5 (측면 통로) + 1,550 (본체) + 653.5 (측면 통로) |
| 프레임 깊이 / 계단 포함 깊이 | 2,640 / 3,270 (= 2,640 + 630) |
| 계단 폭 · 각도 | 630 · 50° |
| 데크 높이 · 난간 높이 | 2,000 · 935.6 |
| 최고 높이 (진공이송기 상단) | 3,664.75 |
| 판넬 화면 하단 높이 | 1,388.04 |
| 측면 하부 표기 | 455.39 (은박 롤 부근, 대상 확인 필요) |

## 2. 형상 판독
- 평면: 본체 1,550 양옆으로 653.5 폭 데크 통로. 우측 통로가 뒤쪽으로 630 더 연장되어 계단(우측으로 1,586.47)과 연결. 계단은 프레임 깊이 밖.
- 호퍼: 역원뿔 호퍼 2기(앞·뒤) 상부에 원통형 진공이송기, 그 사이 작은 각형 호퍼 1기. 평면상 본체 앞쪽 절반.
- 정면: 데크 위 중앙 각형 도징 유닛과 좌상단 경사 배관, 데크 바로 아래 노즐 10열, 하단 실링·커팅 10열, 다리·레벨링 풋.
- 측면: 중앙 세로 제어함, 후면 상부 프린터, 후면 하부 큰 은박 롤.
- 판넬: 데크에서 내려온 L자 암에 매달린 형태, 프레임 앞 좌측 밖으로 돌출.
- 난간: 935.6 높이 패널형(세로 살 격자). 색·재질은 현장 사진으로 확인.

## 3. 현장 지시 (도면보다 우선)
- 2층 데크 전면 확장 약 1,000 (도면에 없음, 재질·모양 동일).
- 계단 방향: 현장 기준 동쪽 (배치도의 남쪽 표기와 다름).

## 4. 현장 배치도 판독 (1차)
- 포장실이 충전실 북쪽. 라인은 충전기에서 북쪽으로 일직선, 벽을 지나 포장실로 이어짐. 두 실 모두 라인이 서쪽 벽 가까이.
- 충전실: 두 실을 합쳐 확장, 가로 약 9~11 m · 세로 약 5~6 m [도면 비율].
- 포장실: 폭 약 4~5 m · 길이 약 10~12 m의 좁고 긴 실, 동쪽은 일반 포장실과 벽으로 구분 [도면 비율].
- 충전실 동쪽에 드럼리프터.
- 확인 필요: 실 이름 옆 숫자(천장 높이로 추정), 실 사이 출입구 위치, 드럼리프터와 IDT 리프터의 관계.

## 5. 현재 모델과의 차이 (11/11 대조, 재구성 대상)
호퍼 형상·배치, 정면 도징 유닛, 판넬(받침대형 → 암 매달림), 데크 평면(전면판 → 측면 통로 + 우측 연장), 계단 위치(프레임 안 → 밖), 난간 형상, 본체 정면·측면 세부, 실 배치(좌우 → 남북).

## 6. 현장 사진 판독
### 6-1. 호퍼 (11/11, 측면 데크에서 본체를 가로질러 촬영 · 사진 좌우 = 기계 앞뒤)
- 호퍼 1·3 (양끝): 넓은 평판 윗판(토글 클램프) 아래 상자형 몸체, 앞면 사각 점검창, 바닥은 바깥 아래쪽으로 경사진 비대칭 쐐기형 → 모서리 배출구. 상부 원통형 진공이송기 드럼(클램프 링 뚜껑, 호스 다수).
- 호퍼 2 (가운데, 주성분): 1·3보다 넓은 각형 박스, 윗면 손잡이 달린 뚜껑(스쿱 수동 투입), 진공이송기 없음, 바닥은 가운데로 모이는 역피라미드 깔때기, 상부 중앙 흰색 원통 부품.
- 번호판: 호퍼 윗판 모서리 파란 번호판(1, 2 확인 · 3 가려짐).
- 하부 도징부: 세로 공압 실린더 다수, 주황 손잡이 밸브, 투명·파랑·흰색 공압 호스 다발, 중앙 하단 흰 천 분진 커버.
- 우측 공압부: 녹색 밸브 블록, 노란 캡 압력계, 은색 주름 진공 호스.
- 표면: 경면에 가까운 광택 스테인리스.
- 데크 바닥: 스테인리스 체크무늬 철판. 난간: 스테인리스 원형 파이프(상단 + 가로 레일 여러 단) — 기존 노란색은 근거 없음, 수정 대상.
- 실내: 흰 클린룸 패널 벽, 천장 매립 LED 평판등 · 원형 디퓨저.

### 6-2. 충전기 본체 · 데크 · 배출부 (11/11, 세척 중 촬영 — 2층 분해 · 1층 노즐 탈거 상태는 참조 제외, 작동 영상으로 보완)
- ~~방향 판독(11/11 초안): 제어함 문 쪽 = 동쪽, 앞 = 남쪽~~ → 6-5 확정 방향으로 대체 (판독 오류).
- 배출 → 이송: 6-5 확정 방향 참조. 배치도와 일치. 경사 구간 · 벽 통과 형상은 컨베이어 사진으로 확정.
- 데크: 사각 스테인리스 기둥, 두꺼운 스테인리스 테두리판, 기둥 상부 경사 보강재(노랑 · 검정 경고 테이프), '머리충돌주의!' 표지. 전면 확장으로 앞 기둥이 본체보다 약 1 m 앞.
- 난간: 스테인리스 원형 파이프 격자(상단 + 가로 3~4단 + 세로), 난간 → 천장 세로 지지봉.
- 원료투입구: 동쪽 난간 중앙, 노란 테이프 개구부 + '원료투입구' 표지. 리프터 바스켓을 난간에 밀착해 하역.
- 현장 표지 '리프터 사용 규칙': 3인 1조(1명 리프터 운전, 2명 물건 하역) → 시나리오(2인 1조 운반) 반영 여부 결정 필요.
- 본체 측면: 중앙 대형 스테인리스 제어함 문, 노란 코일 에어호스 · 에어건.
- 본체 뒤: 하부 은박 롤(가로 축) 언와인더 · 롤러 판, 상부 투명 아크릴 커버 안 프린터.
- 본체 앞: 투명 아크릴 문 → 세로 실링 10열 → 가로 실링 블록(실린더 4) → 커터 블록(실린더 4) → 곡면 엠보 슈트 10 → 10칸 포켓 배출 트레이(투명 커버 2구획 + 손잡이).
- 배출부 부속: 왼쪽 경광등(적 · 황 · 녹) + 조작 버튼 박스(비상정지 포함), 오른쪽 스테인리스 구동부 커버, 하부 공압 레귤레이터, 레벨링 풋.
- 하부: 원통형 스테인리스 받침발 + 빨간 캐스터.
- 실내: 앞쪽 서측 벽가 저울 작업대(IPC 저울 추정), '고온주의' 표지, 바닥 근처 공기 리턴 그릴, 천장 직관형 LED · 원형 스테인리스 디퓨저, 동쪽에 대형 회색 기둥(건물 기둥 여부 확인 필요).
- 확인 필요: 컨트롤 판넬(터치스크린) 위치.

### 6-3. 사용자 확인 (11/11)
- 원칙: 부위가 불확실하면 추측하지 말고 사용자에게 선택지로 질문한다 (사용자 지시 11/11).
- 컨트롤 판넬: 도면대로 데크에서 내려온 L자 암에 매달림, 프레임 앞쪽 남서 바깥.
- 충전실 동쪽 회색 기둥: 건물 기둥.
- 드럼리프터 ↔ 원료투입구 리프터 관계: 사용자가 사진으로 추가 제공 예정.
- 리프터 사용 인원: 3인 1조(1명 운전 · 2명 하역)로 시나리오 변경. 2인 · 1인 선택은 감점. (은박 롤 운반 2인 1조는 유지 — 별도 지시 없음)

### 6-4. 충전기 성형 · 실링 · 배출 세부, 컨트롤 판넬, 작동 영상 (11/11)
- 성형부(위 → 아래): 데크 하부 체크무늬판 바로 아래로 은박 10줄이 성형 숄더(원뿔형)로 내려옴 → 가로 스테인리스 봉(주황 손잡이 노브) → 세로 실링 판 10개(스테인리스 판에 고정 바) → 'SOLPAC' 로고 스테인리스 커버(운전 시 장착, 경고 라벨) → 가로 실링 블록(사각 공압 실린더 4개, HOT SURFACE · CRUSH/CUT 라벨) → 파우치 10줄 → 커터 블록(실린더 4개) → 가로 고정 바(볼트 2개) → 실린더 4개 블록 → 곡면 엠보 슈트 10개 → 10칸 검은 포켓 트레이(투명 커버 2구획 + 양끝 손잡이).
- 양옆: 검은 케이블 체인, 주름 커버 이송 나사, 좌측 클램프 레버.
- 성형부 앞 투명 아크릴 문: 'SP303' 'SOLPAC packaging machine' 표기, '금지 — 도어 인터락 작동중(운전중 개방 시 정지, 운전중 개방금지)', '고온주의' 표지.
- 컨트롤 판넬: 위에서 내려온 기둥(암)에 매달린 흰색 함체, 상단 터치스크린, 하단 버튼 RUN(파랑) · STOP(빨강) · JOG(회색) · RESET(노랑) · FILLING OFF/ON(선택 스위치) · BUZZER, 우측 비상정지 버섯 버튼. 위치는 성형부 앞 서쪽.
- 판넬 서쪽 뒤: 알루미늄 프로파일 케이스 — 은박 프린터 컨트롤러 2대(사용기한 · 제조번호 입력) + 위쪽 비전 PC 모니터 · 키보드 선반 (사용자 확인 11/11). ※ 기존 모델은 프린터 입력을 기계 뒤에서 하도록 되어 있음 → 이 케이스로 이동, 인쇄 헤드는 뒤쪽 유지.
- 배출: 트레이 → 서쪽으로 투명 커버 컨베이어 → 경광등(적 · 황 · 녹) + 조작 박스(비상정지, '불량 조치 시 핀셋 사용' 표지) → 투명 커버를 씌운 경사 컨베이어로 상승.
- 작동 영상(23초): 적색 인쇄 은박 10줄이 연속 성형 · 충전 · 가로 실링 · 커팅되어 곡면 슈트를 따라 포켓 트레이로 떨어짐. 운전 중 SOLPAC 커버 · 아크릴 문 닫힘, 판넬 상태 램프 녹색.

### 6-6. 이송 컨베이어 · 은박 롤 · 프린터 · 리프터 · 실내 (11/11)
- 경사 컨베이어: 투명 커버(손잡이, '안전커버 임의 Open 금지'), 알루미늄 프레임, 진행 방향 화살표와 '불량 조치 시 핀셋 사용' 표지, 회색 A자형 받침대(캐스터) 1개, 시작부에서 수평 → 경사로 꺾이는 곡선 구간. 벽 개구부 옆 인터폰.
- 북쪽 벽: 큰 유리창 2개(포장실이 보임), 컨베이어용 사각 개구부.
- 은박 롤 언와인더(동쪽): 회색 도장 측판, 롤(가로 축) + 곡선 댄서 암, 접합대(클램프 2개, 노란 테이프), 상부 투명 아크릴 롤러 커버(손잡이), 롤러 다수.
- 인쇄 헤드부: 회색 프레임 안 인쇄 유닛, 서보 직선 이송축, 투명 아크릴 커버('안전커버 임의 Open 금지'). 옆에 소형 회색 제어 박스(표시창 · OFF/ON 스위치 · 버튼), FESTO 에어 필터 레귤레이터 2세트, 220V 콘센트, 명판, 루버 통풍구.
- 데크 하부: 체크무늬판, 사각 각관 보 격자.
- 드럼리프터 = 원료투입구 리프터 (같은 설비, 사용 시 투입구 앞으로 이동): 스테인리스 사각 마스트, 양옆 난간 달린 바스켓, 하부 본체(조작 버튼 · 케이블), 빨간 캐스터.

### 9-3. 사진 판독
