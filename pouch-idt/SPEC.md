## 4. 3D 공간
### 4-1. 공간 구성 [추정, 배치도 없음]
- 한 장면에 충전실과 포장실을 두고 사이 벽(창)으로 구분. 충전기 정렬컨베어가 경사로 벽을 지나 포장실 스틱공급장치로 이어짐 [확정: 같은 컨베이어]
- 과정별 시작 시점: 충전실 과정은 충전실 전체, 포장실 과정은 포장실 전체. 다른 실은 간략 모델로 자동 가동 [승계: PTP 단일화면 방식]
- 충전실 2층 데크(계단·난간)를 만들고 호퍼 3기·도징박스·셔터 실린더·충전량 조절 다이얼·진공이송기를 배치 [SOP]
- 1층 충전기 뒤편에 IBC 2기(첨가제·백당)와 이송 호스 [확정]

### 4-3. 파우치 흐름 표현
- 은박 롤 → 성형 → 10열 충전 → 실링 → 커팅 → 정렬컨베어(경사) → 스틱공급장치 → 카토너(6포 + 설명지 → 카톤) → 케이스 프린터(LOT·EXP 인쇄) → 비전 → X-ray → 중량선별기 → 수동포장(대케이스)
- 불량 경로: 충전기 공포배출 컨베어, 카토너 불량품 배출부, 케이스 프린터 리젝터 함, X-ray·중량선별기 배출함
- 정렬컨베어 가동스위치 OFF 동안 파우치는 공포배출 쪽으로 배출(카토너 유입 차단) [SOP]

## 6. 알람·이상사례·IPC UI [승계 + SCENARIO]
- 알람: 빨간색 팝업, 명칭만 표시(코드 없음) → 원인·조치 선택지 4개 → 현장 빨간 ! → RESET → RUN
- 이상사례: 주황색 패널, PTP 3단계(시험·발견 → 빨간 ! 조치 → 재시험·재기동)
- IPC 패널(충전실): 회차 안내('1시간마다 실시' 문구) → 도징 개별 ON/OFF 설정 → 채취(주성분 30포·나머지 20포) → 저울 계량 표(포별 중량, 평균, 판정: 평균 ±4%·개개 ±8%) → 부적합 시 충전량 조절 다이얼 조정 → 재측정
- 평가모드 자동 발생: 이상사례 1회 + (잠정) 해결·재가동 15초 후 알람 1회
